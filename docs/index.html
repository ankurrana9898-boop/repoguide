OPEN-SOURCE · EARLY PROTOTYPE

Find your way around
a GitHub repository.

See its languages, top-level files and places to start reading. Free to use, right in your browser.

Paste a repository homepage URL or enter owner/repository. Private repositories are not supported.

What works today

RepoGuide reads public repository metadata from GitHub: description, default branch, language breakdown and root directory. Follow file links to explore the original source.

Where we’re going

Planned Claude API features include code explanations and guided onboarding. These are not implemented in this prototype. The current version uses no AI model and makes no paid API calls.

Privacy and limits

Your browser contacts GitHub directly. RepoGuide does not ask for credentials or save your searches. GitHub receives your requests and applies its public API limits; some repositories may be unavailable or restricted. This tool does not review the full codebase.
